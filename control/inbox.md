# Inbox — just write. Claude files it for you.

Write each note under the model you want — or don't overthink it: put it under
"Not sure" and Claude sizes the model to the job (small fix → small model,
big build or hard problem → big model).

Claude reads this every hour: it turns each note into a proper task, files it in
queue.md (or for-you.md if it's something only you can do), tags it with the model of
the section you wrote it in, clears your note from here, and works what it can — pinging
your phone at each step. If you haven't written anything, Claude does nothing.

Keep the "##" headings — they're permanent. Just add your lines under them.
(Shortcut: start any line with "idea:" to park a rough thought instead of running it.)
